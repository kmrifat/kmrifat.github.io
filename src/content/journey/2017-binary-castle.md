Binary Castle has run alongside the employed roles since 2017. It started as the
home for the commercial products — the Dr. Assistant line, xPOS and Restulator,
all sold on CodeCanyon and supported from here — and grew into the place the
reusable tooling lives.

Much of it is deliberately built as libraries first — form, table, page-builder
and admin-panel packages that the products then consume — so each new product
starts further along than the last.

The Django backend serving this portfolio runs on Binary Castle infrastructure.
