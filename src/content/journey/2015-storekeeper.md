A student project that turned out to have a long life. It is still the
highest-starred repository on my account, which probably says how many people
were looking for a working JavaFX example with a real database behind it.

Alongside it I published a set of small JavaFX how-to repositories — table
pagination with FXML, communication between controllers, enabling a button on
stage close — that came straight out of problems I hit building it.
