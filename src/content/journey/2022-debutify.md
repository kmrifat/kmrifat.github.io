Shopify app development carries constraints most web work does not: OAuth against
each merchant's store, webhook reliability, per-shop API rate limits, and billing
through Shopify rather than directly.

The `laravel-shopify` package came out of it — a reusable foundation for
API-oriented Shopify apps, instead of rebuilding the same integration layer each
time.
